# Cars93 Data Analysis Using Python

## Project Overview
This project focuses on analyzing the Cars93 dataset using Python. It explores car specifications, prices, horsepower, and mileage to understand different car features through data analysis and visualization.

## Project Objectives
- Analyze car prices and specifications.
- Calculate average city and highway mileage.
- Explore the relationship between horsepower and price.
- Identify useful patterns in the dataset.
- Present insights using charts and graphs.

## Tools & Libraries Used
- Python
- Google Colab / Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Dataset
The project uses the Cars93 dataset containing information about different cars, including price, horsepower, engine size, and fuel mileage.

## Data Analysis & Visualization
- Data loading and inspection
- Data cleaning and preprocessing
- Statistical analysis
- Price and horsepower analysis
- City and highway mileage analysis
- Charts and graphs for visualization

## Key Insights
- The average highway mileage is approximately 29.09 MPG in the analyzed dataset.
- Car prices and horsepower can be compared to understand differences between vehicles.
- Mileage and engine specifications help explore car performance patterns.

## How to Run
1. Download or clone this repository.
2. Open `cars93.ipynb` in Google Colab or Jupyter Notebook.
3. Upload the required Cars93 CSV dataset.
4. Run the notebook cells in order to view the analysis and visualizations.

## Project Files
- `cars93.ipynb` – Python code and analysis
- `cars93.html` – HTML version of the notebook
- `Cars93.csv` – Dataset used for analysis

## Conclusion
This project demonstrates how Python data analysis libraries can be used to explore a car dataset, perform calculations, visualize patterns, and derive useful insights.
